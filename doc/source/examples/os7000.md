# TS Waves in Plane Poiseuille Flow

`examples/os7000` contains the TS-wave / Orr-Sommerfeld setup for plane Poiseuille flow.

## FOM

The FOM case uses eigenfunction input generated by the author's Orr-Sommerfeld solver. The case monitors the energy growth
rate and compares it against linear theory, which should agree to roughly five digits.

## ROM

The ROM user file mirrors the FOM setup, with a modified `rom_userchk` that resolves name conflicts and evaluates inner
products with ROM coefficients.

## Post-Processing

The case README suggests checking the error history with `grep egn logfile > t.e` and plotting the result on a log scale.
